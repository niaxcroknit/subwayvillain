# 2호선 격돌 (subwayvillain)

서울 지하철 2호선 객차 안에서 노약자석·임산부석 민폐 승객과 사건 가해자를 제압하는 가로 모바일 3D 게임입니다. 단일 HTML이고 three.js r128을 씁니다.

- 바로 실행: `game/index.html`을 브라우저에서 열기
- 수정: `source/index.html`을 고친 뒤 `node scripts/build.cjs`
- 검사: `npm install && npm test`
- 인수인계 문서: `START-HERE.md` → `AGENTS.md` → `docs/V5-CHANGES.md`
