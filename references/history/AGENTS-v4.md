# 현재 작업 기준

이 문서는 대화에서 확정한 최신 기준입니다. `references/history/original-AGENTS.md`의 상충하는 오래된 내용보다 우선합니다. 변경 요청이 없다면 승인된 결과를 유지하며 이어서 작업합니다.

- 사용자는 현재 v4의 스타일·속도감을 좋아합니다. 스타일은 `references/approved/style-02.png`의 매끈하고 간결한 모바일 3D 표현입니다. 과거의 구·원기둥 인형, 각진 구형 저폴리, 사실적인 GTA풍으로 되돌리지 않습니다. 새 아트 방향은 이미지 시안으로 먼저 비교·확정합니다.
- 실제 인물은 생성한 3D 렌더 스프라이트입니다. 3D 객차/물리 좌표와 빌보드 캐릭터의 조합이며, 자유 시점 3D 스키닝 모델이라고 설명하지 않습니다.
- 가로 모바일, 한국어 UI, 서울 지하철 2호선, 일반적인 한국 승객 설정을 유지합니다.
- 남녀 주인공 선택·저장이 있고 능력치는 같습니다. 두 주인공 모두 풍차 주먹과 장우산 회전을 사용합니다.
- 무고한 일반석/입석 승객, 피해 승객, 어르신, 임산부는 절대 타격 대상이 아닙니다.
- 공격 대상은 빨간 위반 표시가 붙은 젊은 교통약자석 점유 승객 또는 활성 사건의 가해자뿐입니다. 새 사건은 일반석 취객의 어깨 기대기, 추행 남성의 비노골적인 접촉 시도, 일반 시민에게 시비 걸기입니다. 명확한 가해 행동을 시작하기 전의 탑승객은 공격하지 않습니다.
- 피해자는 곤란한 표정/거부 동작과 초록 보호 표시를 가집니다. 제압 후 안도 표현으로 전환합니다.
- 다음 역마다 같은 객차에 새 사건이 생깁니다. 동시 활성/도착 중 사건은 최대 6건입니다.
- 현재 속도감, 지폐 자동 회수, 즉시 정산을 유지합니다. 정산은 애니메이션과 분리하여 잔액을 즉시 반영하며 중복 지급하지 않습니다.
- 정산 패드는 한 객차에 5곳입니다. 빠른 정산 버튼, 강화 패드 선 정산, 가방 가득 시 자동 정산을 유지합니다. 객차 밖 지폐와 오래 남은 지폐를 놓치지 않습니다.
- `source/index.html`을 수정하고 `node scripts/build.cjs`로 `game/index.html`을 생성합니다. 결과물은 단일 HTML이며 이미지 데이터는 포함됩니다.
- 외부 스크립트는 기존 고정 버전 CDN 조건을 지킵니다. 새 외부 이미지 URL을 도입하지 않습니다. localStorage 접근은 try/catch를 유지합니다.
- 검사 결과와 실제 브라우저/GPU/휴대폰 검증을 구분해 보고합니다. 이 프로젝트의 현 납품물은 실제 모바일 QA를 통과했다고 주장하지 않습니다.
