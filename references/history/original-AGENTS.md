# 2호선 격돌 — 작업 지시서

모바일용 하이퍼캐주얼 3D 게임을 만들어 주세요. 지금까지 만든 버전은 `game/index.html`에 있습니다. 게임 로직은 대체로 쓸 만하지만, **그림 스타일이 의뢰인이 원하는 수준에 못 미칩니다.** 이번 작업의 핵심은 **비주얼을 레퍼런스 수준으로 끌어올리는 것**입니다.

## 1. 한 줄 요약

화이트아웃 서바이벌(Whiteout Survival) 광고 미니게임의 **그림 스타일과 손맛**을 그대로 가져와서, 무대만 **서울 지하철 2호선 객차 안**으로, 인물만 **평범한 한국 승객**으로 바꾼 게임입니다.

## 2. 레퍼런스 (반드시 먼저 보기)

- `refs/whiteout-ad-base.png`: 화이트아웃 광고. 자원을 모으고, 등에 쌓아 나르고, 바닥의 `+100` 패드에 돈을 넣어 확장하는 루프입니다.
- `refs/whiteout-ad-clash.png`: "빙원 격돌" 장면. 주인공이 도끼를 휘둘러 주변 적을 원형으로 쓸어버리고, 드롭이 사방에 흩어지고, 등에는 아이템 탑이 쌓입니다. **의뢰인이 가장 원하는 손맛이 이 장면입니다.**
- `refs/current-version-screenshot.png`: 현재 버전 화면. 이 정도로는 부족하다는 피드백을 받았습니다.

### 레퍼런스에서 가져올 것 / 가져오지 말 것

| 가져올 것 (스타일) | 가져오지 말 것 (설정) |
|---|---|
| 말랑하고 둥근 2~3등신 인형 같은 3D 캐릭터 | 눈밭, 설원, 침엽수, 울타리 |
| 쨍하고 밝은 색, 부드러운 그림자 | 털 파카, 북극곰, 생존·추위 설정 |
| 위에서 비스듬히 내려다보는 카메라 | 도끼, 고기 드롭 |
| 광고 같은 UI: 돈 카운터, 바닥 `+100` 패드, 말풍선 아이콘 | |
| 원형 회전 공격 + 주변 적 일괄 타격 + 드롭 흩뿌림 + 등에 쌓기 | |

의뢰인 말 그대로 옮기면 이렇습니다. "디자인 스타일을 똑같이 해 달랬지, 설정을 똑같이 해 달랬냐. 배경은 여전히 지하철이고 일반인이야."

## 3. 필수 조건

- **가로 화면 전용** 모바일 게임입니다. 폰을 눕혀서 해요. 세로로 들면 회전 안내를 띄우세요.
- 단일 HTML 파일입니다. 외부 스크립트는 `cdnjs.cloudflare.com`, `cdn.jsdelivr.net/npm/`, `unpkg.com` 중 하나에서 **버전을 고정해서**만 불러옵니다. 현재는 `three.js r128`을 씁니다.
- 폰트는 Google Fonts만 쓸 수 있습니다.
- 그 밖의 이미지와 모델은 전부 코드로 생성하거나 data URI로 인라인합니다. 외부 에셋 URL은 차단되는 환경입니다.
- 진행 상황은 `localStorage`에 저장합니다. 읽기와 쓰기는 모두 `try/catch`로 감싸세요.
- 중저가 폰에서도 60fps 근처가 나와야 합니다. 그림자 맵 크기, 메시 수, 픽셀 비율 상한을 신경 써 주세요.
- 모든 UI 텍스트는 한국어입니다.

## 4. 게임 설계 (현재 구현 기준, 유지)

- **무대**: 2호선 객차 내부를 위에서 본 단면입니다.
  - 북쪽 벽에 창문과 문이 있고, 남쪽 벽은 잘라내서 안이 보이게 합니다.
  - 좌석은 양쪽 벽을 따라 놓입니다. 객차 양 끝은 **주황 노약자석**, 가운데에 **분홍 임산부석**, 나머지는 일반석입니다.
  - 창밖으로 지상 구간 도시 풍경이 흘러갑니다.
- **주인공**: 평범한 직장인 김대리입니다. 무기는 **장우산**입니다.
  - 화면 아무 데나 드래그하면 그 자리에 가상 조이스틱이 생깁니다. PC에서는 WASD로도 움직입니다.
  - 적이 사거리 안에 들어오면 **자동으로 원형 회전 공격**을 합니다.
- **빌런**: 노약자석·임산부석에 앉은 젊은 민폐 승객입니다.
  - 머리 위에 **빨간 위반 딱지**를 붙입니다. 예: 위반 · 폰겜 / 위반 · 쩍벌 / 위반 · 못 들은 척 / 위반 · 백팩 자리맡기.
  - **딱지가 붙은 사람만 공격 대상**입니다. 의뢰인이 "아무나 패는 것 같다"고 지적했던 부분이라 꼭 지켜 주세요.
  - 주인공이 다가가면 일어나서 덤빕니다.
- **진짜 교통약자**: 어르신과 임산부입니다. 초록 딱지를 붙이고, 절대 공격 대상이 아닙니다.
  - 빌런을 치운 자리에 줄 서 있던 어르신이 와서 앉고, 주기적으로 "감사 팁"을 줍니다.
- **격돌 웨이브**: 일정 시간마다 다음 역에 정차해서 문이 열리고 빌런 떼가 탑승합니다.
  - 일부는 빈 노약자석으로 달려가고, 일부는 주인공에게 몰려듭니다.
  - 웨이브가 진행될수록 수가 늘어납니다.
- **루프**
  1. 빌런을 처치하면 벌금 딱지(초록 지폐)가 흩어집니다.
  2. 근처에 가면 빨려와서 등에 탑처럼 쌓입니다. 가방 용량만큼만 쌓입니다.
  3. 정산기 패드에 서면 돈으로 바뀝니다.
  4. 바닥 패드에 서 있으면 돈이 빨려 들어가면서 해금됩니다.
- **해금 패드**: 역무원 고용(따라다니며 같이 싸움), 가방 확장, 우산 강화(데미지와 범위 증가), 다음 칸 개방.
- **체력**: 빌런에게 맞으면 체력이 깎이고, 0이 되면 쓰러졌다가 부활합니다. 등에 쌓인 지폐는 그 자리에 떨어집니다.

## 5. 이번 작업에서 가장 중요한 것: 비주얼 품질

현재 버전의 문제점입니다.

1. 캐릭터가 구·원기둥을 조합한 수준이라 레퍼런스의 매끈하고 귀여운 인형 느낌이 안 납니다. 비율, 실루엣, 얼굴 표현이 약합니다.
2. 조명과 재질이 밋밋합니다. 레퍼런스처럼 부드러운 그림자, 은은한 림 라이트, 쨍한 색 대비가 필요합니다.
3. 객차가 휑하고 디테일이 부족합니다. 바닥 패턴, 좌석 모양, 손잡이, 광고판, 노선도 같은 생활감 소품이 필요합니다.
4. 타격감 연출이 레퍼런스보다 약합니다.
   - 휘두를 때 궤적 이펙트가 굵고 밝아야 합니다.
   - 맞은 적은 튕겨 나가야 합니다.
   - 드롭이 사방으로 터지면서 흩어져야 합니다.
   - 등의 탑이 쌓이는 게 눈에 띄어야 합니다.
5. UI가 광고만큼 또렷하지 않습니다. 돈 카운터, 패드 아이콘과 가격, 진행률 채움을 굵고 읽기 쉽게 해 주세요.

권장 방향은 다음과 같습니다. 판단은 맡깁니다.

- 캐릭터는 둥근 지오메트리를 쓰고 셰이딩을 부드럽게 합니다. 툰 계열 재질에 약한 아웃라인을 쓸지도 검토해 주세요.
- 머리가 크고 몸통이 짧은 2~3등신으로 만들고, 눈은 크고 또렷하게 그립니다.
- 같은 사람이 반복돼 보이지 않게 승객마다 옷 색·머리·소품을 다양하게 합니다.
- 카메라는 레퍼런스처럼 가깝게 잡습니다. 캐릭터가 화면 높이의 약 1/8~1/10 크기로 보이게 하고, 주인공을 따라갑니다.
- 히트스톱, 화면 흔들림, 숫자 팝업, 파티클을 레퍼런스 수준으로 넣고, 가능하면 진동도 넣어 주세요.

## 6. 의뢰인 피드백 이력 (같은 실수를 피하려고 적어 둠)

- "도트 안 귀여워 / 유치해, 초등학생 게임 같아": 파스텔 꼬마 2D 도트 버전.
- "모바일인데 왜 PC 화면으로 줘?" → "가로로 돌려야지": 가로 풀스크린 게임 화면이어야 합니다. 웹페이지처럼 보이면 안 됩니다.
- "마인크래프트를 갖고 왔네": 네모 블록 캐릭터는 금지입니다.
- "아무나 공격하는 거 아니야?": 위반 딱지가 붙은 사람만 공격하게 해야 합니다.
- "설정 말고 디자인 스타일을 똑같이": 눈밭·설원 배경은 금지입니다.

## 7. 완료 기준

- [ ] 가로 폰 화면(예: iPhone 13 가로)에서 레퍼런스 광고와 나란히 놓았을 때 같은 장르, 같은 퀄리티 계열로 보인다.
- [ ] 객차 안 무대, 평범한 승객, 딱지 붙은 빌런만 공격하는 규칙이 지켜진다.
- [ ] 회전 공격 → 드롭 흩뿌림 → 등에 쌓기 → 정산 → 패드 해금 루프가 끝까지 막힘 없이 돈다.
- [ ] 웨이브 정차 때 빌런 떼가 탑승하는 "격돌" 순간이 시원하다.
- [ ] 중저가 폰에서 끊김 없이 돈다.
