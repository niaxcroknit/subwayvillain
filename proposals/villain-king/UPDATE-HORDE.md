# 최신 연출 v2

기존 UPDATE-HORDE.md의 이전 설명을 대체합니다.
0~2초: 정상 색 객차, 기존 승객 6명, 빌런왕 입장.
2~4.2초: 빌런왕이 팔을 벌리는 냄새 방출 모션. 2.7초부터 몸 주변에 냄새가 뭉칩니다.
4.2~6초: 화면 전체에 초록빛이 서서히 퍼지고 기존 승객들이 순차 변이합니다.
6초 이후: 기존 승객이 주인공으로 접근. 좌우 옆 객차 연결문에서 추가 승객이 진입합니다.
초록빛은 100명 제압 전까지 유지합니다. 시간으로 해제하지 않습니다.
각 승객은 위치를 유지하며 이동하고, 걷기는 이동 거리에 맞춰 재생합니다. 화면 끝에서 순간 재순환하지 않습니다.
최대 동시 12명, 누적 100명. 방향 전환과 간격 조정 적용. 쓰러진 승객은 사라집니다.
현재 공격은 접근·제압 연출 시안이며 정교한 전용 좀비 공격 스프라이트와 실제 전투 판정은 아직 없습니다.
성능: 30fps 제한, 숨긴 모션 카드는 그리지 않음, 개별 모션 프레임 변경 시만 갱신, 숨긴 탭 정지, 정지 화면 다시 그리기 생략.
실제 사용자 브라우저의 GPU 성능과 체감 렉은 아직 측정하지 않았습니다.
실게임 미적용. 기존 보호 승객 규칙 유지.
