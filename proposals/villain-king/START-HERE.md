# METRO PUNK · 빌런왕 캐릭터 패키지

## 사용자 확정 디자인
키가 작고 어깨가 좁은 왜소한 성인 남성. 구부정한 자세,헝클어진 검은 앞머리,두꺼운 사각 안경,옅은 수염. 낡은 보라 후드·황회색 티·짧은 회갈색 바지·해진 슬립온. 작은 가방과 말린 포스터·배지로 취미인 인상을 줍니다. 큰근육/넓은어깨/큰배/거인으로 바꾸지 않습니다. 보스의 힘은 덩치가 아니라 냄새와 승객 전환입니다.

## 포함 파일
- character-design.png: 지하철 입장 일러스트 + 정면/측면/후면 디자인
- villain-king-portrait.png: 냄새 아우라를 포함한 투명 배경 전신 일러스트
- index.html: 6동작 동시 재생, 4방향 선택, 프레임/속도/일시정지, 입장→승객 전환→돌진→첫 피격 생존 연출 시연
- motions.gif: 6동작 자동 반복 확인
- assets/original: 생성 원본6장
- assets/atlas: 정리한 PNG시트6장, 각각8열4행(2048×640,셀256×160),총192프레임
- assets/atlas-webp: 같은모션의WebP95
- FRAME-SAFETY.json: 원본 전체 추출 및 프레임별 그림경계/여백,3개 재생영역의 검증 정보

## 모션
idle: 구부정한 대기와 미세한 몸 움직임.
walk: 작은 보폭의 입장/이동. 미리보기는 냄새와 파리를 별도 합성합니다.
odor: 웅크림→몸을 펴며 팔 벌리기→냄새 방출→회수.
attack: 마른 체형의 앞으로 밀치기.
hurt: 피격→비틀거림→가슴을 잡고 버팀→회복. 죽지 않습니다.
defeat: 체력 소진 때만 사용하는 무릎 꿇기/쓰러짐,마지막 프레임 유지.

행0정면/행1오른쪽/행2후면/행3왼쪽. 각행8프레임. 다른 방향을 좌우반전하거나 옆모습 하나로 대체하지 않습니다. 스프라이트 셀비율1.6,발기준Y152/160. 모션 간 공통 크기 기준으로 정렬했으며,빈 칸 경계를 넘은 원화는 캐릭터 전체 연결 성분을 기준으로 가져옵니다. 최소6픽셀 여백을 확보했습니다. 이미지 전체를 구부리거나 늘리지 마세요.

## 냄새/승객 전환 설계
현재 index.html의 시각적 시연이며 실제 게임 로직이 아닙니다. 작은 보스가 냄새를 풍기며 입장→냄새가 성인 승객에게 닿음→별도 빌런화 표식→주인공에게 달려듦 순서입니다. 이 시연의 체력바는 첫 피격에 체력을 남겨 ‘한방에 못죽임’을 표현합니다.

게임 통합 시 보스의 첫 타격 즉사 방지/체력/피해상한/페이즈,냄새 범위와쿨다운/전환 대상 수는 별도 구현이 필요합니다. 수치는 아직 사용자 확정이 없습니다. 평소 승객을 무조건 타격 대상으로 바꾸지 말고,냄새에 전환된 상태와 가해자 표식이 있는 동안만 기존 공격 자격에 추가하세요. 냄새가 풀리거나 보스가 제압되면 시민으로 복구하는 처리가 필요합니다. 기존 어르신·임산부·피해 승객·역무원 등 보호 규칙은 유지하는 방향으로 통합하세요.

## 검증/미완료
192프레임의 원본/시트 추출,최소6픽셀 여백,480×320/380×298/240×200 재생영역 경계를 확인했습니다. 6모션×4방향 선택,재생/정지/프레임/입장 다시보기,전환·돌진·생존 시연 상태,최종 쓰러짐 마지막 프레임 유지 및80프레임GIF 구조를 검사했습니다. 원화와 렌더 결과도 육안 확인했습니다.

기존 게임 파일은 수정하지 않았습니다. 실제 게임의 보스전/승객 전환/최종HP/카메라 통합 및 실제 휴대폰 검증은 미완료입니다. 이 패키지를 실제 게임 완성본으로 보고하지 마세요. assets/scene의 두 승객/주인공 시트는 기존v6.9 원화로,연출 비교에만 사용했습니다.

## 재생성
Node20이상, npm install. npm run pack으로 원본에서 아틀라스 재정렬, npm run build로HTML/GIF시연을 다시 만듭니다. 이미지 생성은 내장imagegen으로 했으며 유료fal생성은 사용하지 않았습니다.
