# 감염 승객 전용 공격 · 최신 변경

- 남자 회색 후드, 여자 빨간 재킷 디자인을 참고해 오른쪽/왼쪽 전용 공격 8프레임씩 총 32자세 생성.
- 준비 → 어깨·몸통 당김 → 빠른 두 팔 밀치기 → 접촉 → 회수. 각 승객의 타이밍과 주기를 다르게 적용.
- 공격 범위에 도착하면 위치·발걸음을 고정. 먼 승객은 기존 걷기를 유지.
- 접촉 프레임에만 작은 타격 표시와 주인공 반응. 실제 데미지/전투 판정 미적용 시안.
- 정상 객차 → 보스 팔 벌리기 → 국소 냄새 → 전체 초록빛 → 기존 승객 변이 및 옆칸 진입, 100명 제압 조건은 유지.
- 30fps 제한, 숨긴 모션 카드/숨긴 탭 재생 정지 유지.
- assets/atlas/infected-attack.png: 2048×640, 셀256×160, 8열4행. 행순서: 남오른쪽/남왼쪽/여오른쪽/여왼쪽. 걷기의 방향 행과 혼동하지 마세요.
- assets/scene/infected-attack.webp: 시연에서 사용하는 동일 WebP 시트.
- ATTACK-FRAME-SAFETY.json: 32개 프레임 최소6px 여백 확인.
- scripts/pack-infected-attack.cjs: 원본 패킹 재생성. scripts/build-preview.cjs: 미리보기 생성.
- imagegen 내장 도구 사용. 프롬프트는 IMAGE-PROMPTS.txt 참고.
- 실제 게임 파일 변경 없음. 실기기/GPU 성능은 미측정.
