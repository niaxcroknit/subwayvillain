# METRO PUNK · 역 도착 빌런 2종

index.html을 열면 두 캐릭터의 4방향 행동과 역 도착 상황을 볼 수 있습니다.
문막이: 짧은 머리, 남색 패딩조끼/겨자색 상의/베이지 바지. 팔짱을 끼고 하차문 앞에 버티며 고개만 돌립니다. 주행 중 발생하지 않고 역 도착부터 문 닫힘까지 활성화됩니다.
새치기 탑승: 갈색 단발, 청록 재킷/숯색 바지/주황 크로스백. 어깨부터 밀어 넣고 한 발을 내딛으며 뒤쪽 발이 따라옵니다. 문 열림 동안만 활성화, 문 닫힘 시 진입 중단.
내리는 일반 승객은 보호 대상입니다. 외형 자체가 아니라 해당 상황에서의 방해 행동으로 판정해야 합니다.

각 시트 8열×4행, 프레임256×160, 전체2048×640. 행 순서 정면/오른쪽/뒤/왼쪽. 캐릭터당32, 합계64프레임. FRAME-SAFETY.json에 모든 프레임 최소6px 여백 확인.
assets/original: 생성 원본. assets/atlas: PNG. assets/atlas-webp: 시연용 WebP. assets/scene: 기존 일반 승객 참고 에셋.
characters.png: 캐릭터 비교. station-scene.png: 문 열림 상황. sequence-preview.png: 주행/역 도착/문 열림 비교.

미리보기는30fps 제한, 화면 밖 개별 모션 생략, 프레임 변경 시만 개별 카드 다시 그리기, 숨긴 탭 정지.
실제 게임 파일에는 미적용. 게임의 역 이벤트/문 상태/타격 판정과 연결해야 합니다. 기존 노약자·임산부·일반 시민 보호 규칙을 유지합니다.
검증:64프레임 여백, 주행/도착/열림/닫힘 활성 조건,500회 시연 갱신,상황별 이미지. 실제 모바일 GPU 성능은 미측정.

재생성: Node20이상, npm install, npm run pack, npm run build.
imagegen 내장 도구 사용. 프롬프트 요약은 IMAGE-PROMPTS.txt 참고.
