# v5.2 — 2D 자연스러운 보행 개선

최신 사용자 선택은 ‘유료 3D 생성 대신 2D를 최대한 자연스럽게’입니다. fal 업로드·모델 생성은 실행하지 않았고, 기존 2D 렌더 캐릭터 + 3D 객차 방식을 유지했습니다.

## 바뀐 것

- 주인공의 이동 거리 기반 8프레임 보행을 유지하고, 대각선 방향 표현과 좌우 반전 매핑을 추가했습니다. 방향 경계에는 여유 구간이 있어 입력이 살짝 흔들려도 앞뒤가 자주 바뀌지 않습니다.
- NPC가 정지 이미지를 이동시키던 것을 각 유형의 실제 보행 프레임으로 교체했습니다. 일반 남녀 승객, 어르신, 임산부, 역무원, 일반 사건 가해자, 취객, 보스, 몰카범에 별도 보행 이미지를 적용했습니다.
- 각 NPC는 실제 이동 거리에 따라 발이 움직입니다. 어르신은 더 짧은 보폭을 사용합니다. 전역 시간으로 발이 헛돌지 않습니다.
- 출발과 정지를 감속 곡선으로 연결하고, 목표 지점 앞에서 감속해 멈추도록 공통 steer 로직을 갱신했습니다. 압축된 객차 좌표에서도 가로·세로의 실질 이동 속도가 일관되도록 했습니다.
- NPC는 멈출 때 발을 짚는 프레임을 유지해 얼굴·체형·복장이 갑자기 바뀌는 것을 줄입니다. 좌석·사건·특수 포즈는 필요할 때 해당 아틀라스로 복귀합니다.
- 주행 중 몸 전체를 흔들거나 납작하게 만드는 효과는 쓰지 않습니다. 모든 NPC의 최종 회전 뒤에 이미지 폭을 보정해 회전 중 폭이 흔들리는 현상도 줄였습니다.
- 역무원·보스·몰카범의 정지 아틀라스는 새 보행 이미지와 복장이 맞도록 정리했습니다. 역무원은 빈손, 보스는 검정 반팔 근육질, 몰카범은 남색 후드·낮게 든 폰입니다.

## 자산

새 NPC 아틀라스 5장: walk-civilians, walk-protected, walk-staff, walk-special, walk-incident. 각 1024×512, 8열×4행, 128×128 셀입니다. 각 파일은 인물 2종의 정면/후면 보행 8프레임씩입니다. 기존 주인공 아틀라스는 2048×1024의 4방향×8프레임을 유지합니다. 총 자산 키는 15개입니다.

내장 이미지 생성 도구로 ‘8열×4행, 투명 배경, 승인된 매끈한 모바일 렌더 톤, 발·손 전체가 셀 안에, 같은 크기와 카메라, 자연스러운 연속 보행, 바닥·그림자·텍스트·효과 없음’을 요청했습니다. 프레임별 자동 확대 대신 전체 주기에 공통 배율과 몸통 중심/발 지면 정렬을 적용했습니다. 두 인물은 파일마다 다음과 같습니다.

- civilians: 회색 후드 남성 / 빨간 카디건 여성
- protected: 베이지 재킷·지팡이 어르신 / 크림 스웨터 임산부
- staff: 파란 근무복·반사띠·모자·빈손 역무원 / 보라 셔츠 남성
- special: 검정 반팔 근육질 보스 / 남색 후드·폰 몰카범
- incident: 갈색 재킷 취객 / 베이지 재킷 여성

## 유지·검증·한계

v5의 남녀 선택, 풍차/우산, 대시, 편의점 다중 구매 후 출발, 패드 제거, 주행 중 진상 유입, 보스·도감·질서도·칭호, 일반석 휴식, 보호 대상과 즉시 정산을 유지했습니다.

기존 검사 전부와 NPC 10유형의 보행 프레임 전환, 정지 중 위상 고정, 8구간 방향 UV 범위, 대기/사건 포즈 복귀, 목표 지점 감속·넘침 방지, 30/60fps 조향 일치 검사가 통과했습니다. 소프트웨어 이미지 렌더도 수행했습니다.

실제 브라우저 GPU·실제 휴대폰 입력/속도는 검증하지 않았습니다. 8구간 방향 판정 일부는 원본 프레임의 좌우 반전으로 표현하며, 모든 방향의 독립 원화나 자유 회전 3D 모델은 아닙니다. 원화 프레임 간 미세한 형태 차이는 남을 수 있습니다.
