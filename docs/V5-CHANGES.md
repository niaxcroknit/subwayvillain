## 2. 임시 아트 — 새로 생성해야 함 (우선순위 순)

현재 아래 그림은 기존 그림을 늘리거나 재색해 만든 임시본입니다. `scripts/claude-art/README.md`에 만든 방법이 있습니다. 승인 스타일(`references/approved/style-02.png`, 기존 아틀라스와 같은 렌더 톤)로 **1024×1024, 4×4 칸, 256px 셀, 발끝까지 셀 안에, 투명 배경**으로 다시 생성해 주세요.

1. **incidents.png 전체 재생성**: 원본 0~2행은 발목 아래가 잘려 있었습니다(사용자가 "다리 짤렸다"고 지적). 지금은 신발을 덧그린 상태입니다. 칸 배치는 그대로 유지합니다.
2. **boss.png '선빵 진상'**: 사용자 요청은 "헬스 많이 한 몸, 남들보다 조금만 크게". 몸에 붙는 검정 반팔, 넓은 어깨와 굵은 팔, 시비 거는 표정. 2열에 0행 앞·공격, 1행 뒤·공격, 2행 앞·대기, 3행 뒤·대기(incidents 2열과 같은 배치).
3. **guard.png 역무원**: 2호선 역무원 근무복(남색 모자, 파란 셔츠 또는 조끼, 형광 반사띠), **빈손**. 0열에 2행 앞 서기, 3행 뒤 서기. 가능하면 걷기 프레임도.
4. **herosit.png 주인공 앉은 모습**: 남(0열)/여(1열) 주인공과 같은 옷(카키 재킷). 0행 앞·앉음, 1행 뒤·앉음.
5. **spycam.png 몰카범**: 남색 후드, 폰을 낮게 들어 촬영하는 자세. 노골적인 묘사는 금지. 0열에 2행 앞, 3행 뒤.
6. (선택) 승객과 주인공의 걷기 옆모습 프레임. 지금은 대기 옆모습에 튕김만 줘서 걷는 느낌을 냅니다.

새 PNG로 `assets/atlas/<키>.png`만 바꾸고 빌드하면 코드는 그대로 동작합니다.

## 3. 열린 과제 (사용자가 아직 "애매하다"고 함)

Claude가 추정한 원인입니다. 사용자에게 어느 쪽인지 아직 답을 받지 못했습니다.

1. **손맛:** 공격이 전부 자동이라 "내가 때렸다"는 느낌이 약합니다. 직접 누르는 강공격·필살기, 타격 시 더 큰 히트스톱과 날아가는 연출을 후보로 봅니다.
2. **목표:** 역마다 승패 조건이 흐립니다. "다음 역까지 5명 제압"이나 별 3개 같은 짧은 목표가 후보입니다.
3. **그림:** 컨셉 이미지의 말랑한 2~3등신에 비해 지금 캐릭터는 실사 비율입니다.

밸런스는 미확정입니다. 보스 체력(×7), 카드 가격, 유입 간격, 역 간격은 실제 플레이로 조정이 필요합니다.

## 4. 알려진 한계와 주의점

- 헤드리스 렌더는 실제 속도보다 훨씬 느려서, 긴 루프(완주 등)는 상태값을 바꿔 가며 확인했습니다. 실제 폰에서의 fps, 터치, 사운드는 확인하지 않았습니다.
- 빈 노약자석이 생기면 줄 선 어르신이 먼저 차지하는 경우가 많습니다. 그래서 달리는 중 유입은 사건 위주이고, 노약자석 진상은 역에서 어르신이 내린 뒤에 주로 생깁니다.
- 질서 회복도는 시작할 때 0%(모든 노약자석에 진상)이고, 정리할수록 오릅니다.
- `btnModels`(인물 보기)와 `주인공 변경`은 상점·오버레이와 동시에 쓰는 경우를 막지 않았습니다.
- 사건 그림은 덧그린 신발이 가까이서 보면 티가 납니다(위 2-1).
