# v6 변경 요약 · 코드 위치 · 남은 과제

v5 → v6 (Claude, 2026-11-13). 사용자 요청: "팰 때 화면 흔들림 추가" + 완성도·중독성 제안 전부 반영.
모든 기능은 **새 그림 없이 코드만으로** 만들었습니다. 캡처: `outputs/claude-v6/` (헤드리스 Chrome + SwiftShader, 844×390).

## 1. 타격감

| 기능 | 동작 | 코드 (`source/index.html`) |
|---|---|---|
| 화면 흔들림 | 충격량(trauma)이 쌓이고 제곱에 비례해 흔들림 + 살짝 기울기 + 맞은 방향으로 툭 밀리는 킥. 카메라 추적과 분리돼 누적되지 않음. 기존 「흔들림」 버튼으로 끔 | `shake`, `kick`, update 안 `// 흔들림` |
| 타격·제압 | 타격마다 히트스톱 0.02~0.05초, 치명타는 더 큼. 제압 시 0.06초 정지 + 큰 흔들림 + 킥 | `strike`, `killVillain` |
| 한방 게이지 | 때리면 +2.5, 제압 +9(사건 +14, 보스 +20). 100%면 「한방」 버튼(PC: E/Q)이 빛남. 누르면 0.85초 슬로모션 + 화면 번쩍 + 넓은 범위 큰 피해로 한꺼번에 날림 | `gainUlt`, `activateUlt`, `doUlt`, `ultUI`, 루프 `S.slowT` |

## 5. 완성도

- 첫 판 안내(한 번만): 이동 → 빨간 딱지 진상 위 화살표 → 벌금 줍기 → 구간 미션. 이후 처음 겪는 상황마다 한 번씩 팁(한방, 몰카 도주, 사건 놓침, 보스 기술). `tutTick`, `tip`, `SAVE.tut`, `SAVE.tips`
- 편의점·노선도·도감·오늘 미션이 열린 동안 「주인공 변경」 「인물 보기」가 눌리지 않게 막음.
- 시작 질서도: 노약자석 3자리 중 2자리만 진상으로 시작하고, 질서 공식을 비율로 바꿔 처음부터 0%로 보이지 않음. `orderTick`

## 6. 저장 (localStorage `line2clash-v1`, 기존 값과 병합)

새 필드: `justice`, `cos{umb,jk,fx,own[]}`, `stamps{역번호:별}`, `tut`, `tips{}`, `daily{date,list[]}`, `att{last,streak}`, `bossKills{역:횟수}`, `dexTier{종류:단계}`. 값이 깨져 있으면 기본값으로 되돌립니다.

벌금 딱지 한 장 값은 이제 주울 때의 값(`billVal()`: 기본 ₩5 × 바퀴 × 정의감 × 이벤트)을 지폐에 기록해 정산합니다. 값이 없는 지폐는 ₩5로 계산합니다.
