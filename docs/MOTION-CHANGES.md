# v5.1 — 이동 모션 수정

사용자의 최신 요청은 이동 중 캐릭터가 종이처럼 움직이고 매끄럽지 않은 문제를 점검하는 것입니다. CODEX-MESSAGE.txt의 임시 보스·역무원 등 아트 교체 요청은 배경 자료로 읽었으며 이번에는 보행에 필요한 아트와 코드만 수정했습니다.

## 원인

- v5의 좌우 이동은 실제 보행 프레임 대신 1행의 옆모습 대기 이미지를 사용했습니다.
- 프레임은 전역 시간으로 진행되어 발의 속도와 실제 이동 속도가 분리되어 있었습니다.
- 그림 전체를 매 프레임 회전·상하 이동·가로세로 확대/축소하고 NPC를 좌우 반전하여 평면이 흔들리는 느낌을 강화했습니다.
- 입력 방향과 관성의 실제 진행 방향이 달라질 수 있었고, 방향 경계 근처에서 그림이 교차 전환되었습니다.
- 가로 간격 압축 보정을 회전 적용 전에 계산해 방향 전환 시 이미지 폭이 흔들릴 수 있었습니다.

## 변경

- 남녀 주인공별로 앞·오른쪽·뒤·왼쪽 보행을 각각 8프레임씩 새로 제작했습니다.
- `assets/atlas/walk-male.png`, `walk-female.png`는 2048×1024, 8열×4행, 셀 256×256입니다. 행 순서는 앞/오른쪽/뒤/왼쪽입니다.
- 전 프레임에 같은 배율을 적용하고 몸통 중심과 발 지면을 맞춰, 프레임별 크기 자동 보정 때문에 몸이 커졌다 작아지는 것을 방지했습니다.
- `locomotionSample()`은 실제 이동 거리로 발의 위상을 진행합니다. 멈추면 발도 멈추고 순간이동은 보폭에 더하지 않습니다. 보행 한 주기는 2.2 월드 거리입니다.
- 방향 전환에 약 8도 여유 구간을 두어 경계에서 이미지가 덜컥 바뀌는 현상을 줄였습니다.
- 이동 중 그림 전체의 롤 회전, 가짜 튕김, 스쿼시/스트레치, NPC 좌우 반전을 제거했습니다.
- 주인공 방향을 입력 방향 대신 실제 관성 속도에 맞춥니다. 정지 감속을 빠르게 하고 아주 작은 잔여 속도를 0으로 정리했습니다. 벽에 막힌 축의 속도도 지웁니다.
- 최종 회전 후 아트 폭을 보정하여 방향이 바뀌어도 크기가 유지됩니다.

## 유지

v5의 상점 다중 구매 후 출발, 바닥 패드 제거, 역 도착 정산, 주행 중 진상 유입, 보호 대상 규칙, 보스·도감·몰카 사건·질서 회복도·칭호, 일반석 휴식, 대시·회피는 유지했습니다. 남녀 능력치 및 v5의 기본 이동 속도·전투 수치를 임의로 바꾸지 않았습니다.

## 실제 3D와의 차이

이번 수정은 방향별 3D 렌더 이미지를 사용하는 기존 빌보드 구조 안의 보행 개선입니다. 자유 회전·스키닝·실시간 입체 모델로 교체한 것은 아닙니다. 방향은 네 구간으로 전환되며 무제한 연속 각도는 아닙니다. NPC의 별도 보행 아틀라스와 일부 임시 보스·역무원 아트는 이번 범위에서 새로 제작하지 않았습니다.

## 검증

기존 v5 smoke 검사 전체 통과. 추가 검사는 좌우 8프레임 전환, 이동 거리에 따른 위상, 정지 중 위상 고정, 방향 경계 안정화, 회전 시 폭/높이 고정, 종이식 회전·변형 제거, 순간이동 제외, 30/60fps 이동 거리 일치입니다.

실제 브라우저 GPU 및 실제 휴대폰의 터치/프레임레이트는 이번에 검증하지 않았습니다. 소프트웨어 렌더와 비교 애니메이션은 진단용이며 브라우저 게임 캡처가 아닙니다.

## 아트 제작 명세

내장 이미지 생성 도구로 승인된 주인공 아틀라스를 스타일·복장 참고로 사용했습니다. 남녀 각각 8열×4행, 동일한 카메라/크기, 매끈하고 간결한 모바일 3D, 카키 재킷·크림 상의·짙은 바지·흰 운동화, 투명 배경, 발과 손 잘림 없음, 4방향의 자연스러운 8단계 연속 보행, 과장된 튕김·변형·전투 자세·모션 효과 없음으로 요청했습니다. 원본은 assets/original/walk-male.png 및 walk-female.png입니다.
