# 2호선 격돌 — 적용 버전

`line2-clash-play.html`을 브라우저에서 엽니다. ZIP에서는 `game/index.html`입니다.

- 시작 화면에서 남자·여자 주인공을 선택합니다. 둘의 능력치는 같습니다.
- 화면 드래그 / WASD / 방향키로 이동합니다.
- 가까운 공격 대상에게 자동 공격합니다. 아래 버튼 또는 F키로 풍차 주먹과 우산 회전을 전환합니다.
- 위의 ‘주인공 변경’으로 진행도를 유지한 채 주인공을 바꿀 수 있습니다.
- 초록 지폐를 모으면 중앙·서쪽 정산 패드뿐 아니라 강화 패드에서도 가방을 먼저 정산합니다. 정산 금액은 애니메이션 종료를 기다리지 않고 즉시 잔액에 반영됩니다.
- 상단 ‘빠른 정산’ 버튼으로 어느 위치에서든 가방을 비울 수 있습니다. 가방이 가득 차면 자동 정산되어 수집이 멈추지 않습니다.
- 기본 가방 32장, 수집 반경 3.8로 자동 수집합니다. 1.6초 이상 남은 돈은 거리와 무관하게 회수합니다.
- 객차의 가로 간격을 28% 줄이고 이동 속도를 높였습니다. 떨어진 지폐는 접근할 수 있는 통로 안에 남습니다.
- 위반 승객 3명을 제압할 때마다 순찰 보너스 ₩30을 받습니다.
- 이미 객차 밖에 놓인 지폐까지 매 프레임 통로 안으로 회수합니다. 이동 속도 6.3, 공격 간격 약 0.4초, 수집 애니메이션 약 0.125초로 템포를 높였습니다.

## 공격 규칙

노약자석·임산부석의 젊은 위반 승객에 더해, 명확한 가해 행동을 하는 일반석 취객, 추행 남성, 일반 시민을 위협하는 시비 승객도 공격 대상입니다. 일반석에 앉거나 서 있다는 이유만으로는 공격되지 않습니다. 피해 승객·어르신·임산부는 보호되며 빨간 위반 표시가 없습니다.

취객은 옆 승객의 어깨에 기대고 피해 승객은 곤란한 표정을 짓습니다. 추행 사건은 불쾌한 접촉 시도에 피해 승객이 피하며 거부하는 비노골적 장면입니다. 시비 사건은 일반 시민을 위협하는 행동과 도움 요청으로 구분합니다. 제압 후 피해 승객의 표정은 안도로 전환됩니다.

다음 역마다 같은 객차에 새 사건의 가해 승객이 걸어 들어옵니다. 탑승 중인 승객은 공격되지 않으며, 위반 행동을 시작한 뒤에만 표시와 공격 판정이 활성화됩니다. 동시 사건은 6건 이하로 제한됩니다. 객차 내 정산 패드는 5곳입니다.

## 표현 방식과 파일

02번 시안의 매끈한 캐릭터 표현은 생성한 3D 렌더 스프라이트로 적용했습니다. 이동·공격은 프레임 애니메이션이며 객차·이동·거리·좌석 판정은 Three.js의 3D 공간에서 작동합니다. 캐릭터는 자유 시점으로 회전하는 3D 모델이 아닙니다.

주인공 남녀 및 승객·사건용 이미지 4장을 HTML에 인라인했습니다. 별도 이미지 URL이 필요하지 않습니다. Three.js r128 및 Google Fonts를 읽을 인터넷 연결은 필요합니다. 선택과 진행도는 localStorage에 저장됩니다.

## 검증

실제 Three.js 객체를 사용한 실행 검사에서 남녀 선택·저장·진행도 유지, 동일 능력치, 공격 대상 제한, 풍차/우산 전환, 처치·드롭·수집·정산·가방 강화, 이미지 디코딩·프레임 범위·아틀라스 셰이더 연결을 확인했습니다. WebGL 렌더러를 대체한 실행 검사 및 소프트웨어 렌더 확인이며, 실제 브라우저 GPU 렌더링과 모바일 성능은 검증하지 않았습니다.
