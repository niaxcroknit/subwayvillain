# v5.5 방향 및 보행 수정

사용자 피드백: 모든 캐릭터에 정면이 없고 사선으로 끌리는 것 같음. 이전 자동 검사는 프레임·UV 변경을 확인했을 뿐 원화의 실제 시선과 보행 인상을 보장하지 않았음.

## 변경
- 남녀 주인공과 NPC/백팩을 포함한 16유형에 실제 정면/오른쪽 옆면/후면/왼쪽 옆면을 별도로 그린 dir-* 아틀라스 9장 추가. 반전으로 방향을 만들지 않음.
- 각 행은 8프레임. 주인공은 8열×4행(1024×512), 두 유형을 담은 NPC 시트는 8열×8행(1024×1024). 역할별 복장·머리·가방 색의 식별 기준 유지. 생성 원화이므로 이전 얼굴의 픽셀 단위 일치는 아님.
- 카메라의 고정 수평 시점에 대해 실제 물리 이동 벡터를 변환해서 방향을 선택. 월드 yaw만으로 사선 이미지를 고르던 방식을 제거.
- 대각선은 가장 가까운 4방향에 배정하고 경계에 작은 여유를 줌. 8방향 독립 원화나 연속 3D 회전이 아님.
- 이미지 전체를 구부리거나 회전시키지 않으며 일정한 월드 크기를 유지. 정지 시 같은 방향의 발을 내리는 프레임을 사용. 주인공 보행 주기 거리 2.2→1.5, 일반 NPC 1.85→1.2, 어르신 1.35→0.82로 조정해 같은 이동거리에서 발 동작을 늘림. 이동 속도·대시·열차 속도는 유지.
- 좌석/사건/공격 연출은 기존 전용 그림 유지. 보행 및 일반 대기 자세에 새 방향 원화 적용.

## 확인
preview/motion.html을 열면 16유형을 선택하고 정면/좌우/후면을 동시에 재생·정지·프레임별 확인 가능. 이 페이지는 원화 보행 확인용이며 전체 게임의 실제 기기 테스트를 대체하지 않음.

기존 게임 규칙·남녀 선택·백팩 앞가방 보호 등은 유지. 자동 검사는 방향별 독립 행 및 카메라 기준 이동, 거리 기반 프레임·정지·방향 경계·순간이동·일정 크기·30/60fps 일치와 기존 게임 규칙을 확인. 실제 브라우저 GPU 및 휴대폰 검증 여부는 최종 보고에서 별도 명시.
