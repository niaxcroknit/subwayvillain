# 클로드 전달 — 2호선 격돌

## 최신 사용자 확정
- 여자 주먹은 기존 풍차주먹 원화/동작/속도 그대로 유지. 빠른 잽·스트레이트나 새 고속 풍차로 바꾸지 않음.
- 남자만 어깨와 몸통을 크게 쓰는 넓은 주먹으로 변경할 것.
- 새 아이템 시안: 빨간 소화기, 가방, 야구방망이. 야구방망이는 우산처럼 전방으로 휘두르되 깊은 준비·빠른 타격·긴 후속 동작으로 더 묵직하게.
- UI에서 공격 종류를 설명하는 ‘일반’ 문구를 사용하지 않음.
- 팔/발/무기 끝이 단 한 프레임도 잘리면 안 됨. 원본에서 칸 경계를 넘는 그림을 칸 사각형으로 잘라 추출하지 말 것.
- 기존 캐릭터 스타일 유지, 2D 방식 유지. fal 유료 생성이나 실제3D 전환 요청 없음.

## 현재 적용 상태 — 혼동 금지
- game/index.html은 v5.7 실행 가능한 전체 기존 게임. 여자 원래 풍차는 이미 이 게임에 그대로 있음. 이번 전달 과정에서 게임 로직을 추가 변경하지 않음.
- source/index.html과 assets/atlas가 이 게임의 빌드 소스.
- proposals/attacks/index.html 및 motion-preview.gif는 새로운 공격 시안. 여자 카드만 원본 게임의 실제 hero-female.png, 4프레임×12fps, 기본 공격0.36초/기본 간격0.42초로 복구함. 게임의 장갑 강화에 따른 기존 속도 보정은 유지 대상.
- 남자 넓은 주먹과 새 아이템3종은 아직 게임 전투/상점에 통합하지 않음. 시안은 사선 한 시점이며 게임용 네 방향 전환은 미완료.
- 우산 전방90도, 구매40원/활성 플레이120초, 히트스톱/피격 피드백은 기존 v5.7에 적용돼 있음.
- proposals/icon/app-icon.png는 게임 그림체에 맞춰 그린 문 열리는 지하철 아이콘. 아직 앱 설정에 연결하지 않음.

## 클로드의 다음 작업
1. AGENTS.md와 docs/CLAUDE-HANDOFF.md, 기존 최신 docs/IMPACT.md를 읽고 게임/시안을 실행해 파악.
2. 여자 원래 풍차는 건드리지 않고 남자 주먹을 새 넓은 주먹으로 통합.
3. 소화기/가방/방망이 시안을 기존2D 외형과4방향 보행에 맞춰 전투/상점에 통합. 새 아이템의 가격/지속시간은 아직 사용자 확정이 없으므로 기존 우산의40원/120초를 다른 아이템에도 확정된 요구로 간주하지 않음.
4. 보호 대상 및 태그가 붙은 가해자만 공격하는 규칙 유지. 앞가방 승객 보호, 무고한 시민/어르신/임산부/역무원 보호 유지.
5. 실제 모바일 가로화면, 카메라 가장자리, 모든 공격 방향·프레임에서 팔/발/물건 끝 잘림을 검증. 아직 실제게임 통합 시 잘림 검증을 완료한 것으로 보고하지 않음.
6. npm test와 npm run build를 실행하고 실제 기기 확인과 자동 검사를 구분해 보고.
